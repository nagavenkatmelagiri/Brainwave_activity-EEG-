# 🧠 Brainwave Activity Analysis using EEG Data

This project analyzes EEG (Electroencephalogram) brainwave signals to understand different brain activity patterns. It demonstrates how data science and machine learning can be applied to biomedical signal processing.

## 📊 Dataset
EEG brainwave dataset containing signal values for different frequency bands.

## 🛠 Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 🔍 Features
- Data preprocessing and cleaning
- Visualization of brainwave signals
- Feature extraction from EEG data
- Basic machine learning model for classification
